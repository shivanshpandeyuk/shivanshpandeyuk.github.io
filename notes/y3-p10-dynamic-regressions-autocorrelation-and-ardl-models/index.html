Lecture Notes

Regression and Autocorrelation

Regressive models go beyond univariate modelling, we allow the function to be generated not just by its lags and some errors but also be influenced by other variables in a causal relationship.

OLS regression of time series e.g.

yt=βxt+uty_t = \beta x_t + u_tyt​=βxt​+ut​

will not be efficient if there is autocorrelation.

There are three ways to eliminate this autocorrelation, namely,

  1. Make errors uncorrelated - by using Prais-Winsten or Cochrane-Orcutt methods to specify the relation i.e. this is a GLS method
  2. Include the omitted dynamics - we use ARDL models that will overcome the misspecification of omitted dynamics.
  3. HAC standard errors (heteroscedasticity, and auto-correlation corrected)

Prais-Winsten, Cochrane-Orcutt (GLS)

We seek to estimate the auto-correlation, we believe it is an AR(1) process

yt=βxt+ut ut=ρut−1+ϵty_t = \beta x_t + u_t \\ \ \\ u_t = \rho u_{t-1} + \epsilon_tyt​=βxt​+ut​ ut​=ρut−1​+ϵt​
  • where ϵ\epsilonϵ is not introducing endogeneity as E(ϵ∣x)=0E(\epsilon | x) = 0E(ϵ∣x)=0 and, E(ϵ2∣X)=σ2ItE(\epsilon^2 | X) = \sigma^2 I_tE(ϵ2∣X)=σ2It​, ItI_tIt​ is identity matrix

Define the set of errors over time as

u=[u1u2⋮ut]u = \begin{bmatrix} u_{1} \\ u_{2} \\ \vdots \\ u_{t} \end{bmatrix}u=​u1​u2​⋮ut​​​

Variance-Covariance Matrix

The variance-covariance matrix of uuu is

  • The Diagonal: Notice the 111s running down the center. This represents the variance of the error at any given time ttt.
  • The Off-Diagonal: Notice the ρ,ρ2,ρ3...\rho, \rho^2, \rho^3...ρ,ρ2,ρ3... terms. These show that the error today is correlated with the error tomorrow (ρ\rhoρ), day after (ρ2\rho^2ρ2), etc.
  • The Meaning: Because the off-diagonals are not zero, we cannot use regular OLS. We need a “weighting matrix” to clean this up.
  • σu2\sigma^2_uσu2​ = unconditional variance, so for diagonals it is active for off-diagonals it is dampened.

The PPP Matrix

In GLS, we look for a matrix PPP that “whitens” the errors. Think of PPP as a filter. When we multiply our data by PPP, it removes the patterns in the errors, leaving only the white noise.

The matrix PPP is a specific construction designed so that PΩP′=IP \Omega P' = IPΩP′=I.

To find PPP, we effectively need to find the “square root” of the inverse of Ω\OmegaΩ. We use a method called Cholesky Decomposition.

Ω=σu2(Correlation Matrix)   ⟹  Ω−1=σu−2(Correlation Matrix)−1\Omega = \sigma^2_u (\text{Correlation Matrix}) \\ \ \\ \implies \Omega^{-1} = \sigma_u^{-2} (\text{Correlation Matrix})^{-1}Ω=σu2​(Correlation Matrix) ⟹Ω−1=σu−2​(Correlation Matrix)−1

but the inverse correlation matrix is the standard AR(1) tridiagonal form. This final part requires Cholesky decomposition, it finds a lower-triangular matrix MMM s.t. M′M=Ω−1M'M = \Omega^{-1}M′M=Ω−1

  ⟹  Ω−1=P=σu−11−ρ2×(Scaled Correlation Matrix−1) \implies \sqrt{\Omega^{-1}} = P = \frac{\sigma_u^{-1}}{\sqrt {1-\rho^2}} \times \sqrt {(\text{Scaled Correlation Matrix}^{-1})}⟹Ω−1​=P=1−ρ2​σu−1​​×(Scaled Correlation Matrix−1)​

  • Note that the top left is the only one that is 1, this is because y0y_0y0​ is a known constant.

Thus GLS here amounts to regressing

for t =1: 1−ρ2 y1=1−ρ2 βx1+1−ρ2 u1 for t > 1: yt−ρyt−1=(xt−ρxt−1)β+ut−ρut−1\text{for t =1: } \sqrt{1 - \rho^2} \ y_1 = \sqrt{1 - \rho^2} \ \beta x_1 + \sqrt{1 - \rho^2} \ u_1 \\ \ \\ \text{for t > 1: }y_t - \rho y_{t-1} = (x_t - \rho x_{t-1}) \beta + u_t - \rho u_{t-1}for t =1: 1−ρ2​ y1​=1−ρ2​ βx1​+1−ρ2​ u1​ for t > 1: yt​−ρyt−1​=(xt​−ρxt−1​)β+ut​−ρut−1​
ObservationTransformed Equation
First t=1t=1t=11−ρ2y1=β(1−ρ2x1)+error\sqrt{1-\rho^2}y_1 = \beta(\sqrt{1-\rho^2}x_1) + \text{error}1−ρ2​y1​=β(1−ρ2​x1​)+error
Others t>1t>1t>1(yt−ρyt−1)=β(xt−ρxt−1)+εt(y_t - \rho y_{t-1}) = \beta(x_t - \rho x_{t-1}) + \varepsilon_t(yt​−ρyt−1​)=β(xt​−ρxt−1​)+εt​
  • Prais-Winsten does this scalar transform to the first observation so that it can be kept.
  • Cochrane-Orcutt discards the first observation and only uses the quasi-differenced equations.

In small datasets, losing the first observation (Cochrane-Orcutt) can lead to a significant loss of statistical power.

Prais-Winsten is generally preferred because it uses all TTT observations.

Feasible Prais-Winsten Process

Of course we do not know the actual variance-covariance matrix, we have to estimate it.

  1. Get the residuals u^t\hat u_tu^t​ Run the regression of OLS
yt=βxt+uty_t = \beta x_t + u_tyt​=βxt​+ut​

Even though OLS is inefficient here, it is still “consistent,” meaning the residuals (u^t)(\hat{u}_t)(u^t​) you get are good estimates of the actual errors.

  1. Estimate ρ\rhoρ You run the second regression to specify the AR(1)
u^=ρu^t−1+ϵt\hat u = \rho \hat u_{t-1} + \epsilon _tu^=ρu^t−1​+ϵt​
  1. Do the GLS regression You then use ρ^\hat \rhoρ^​, in your P matrix to transform the data and do the final clean regression.

ARDL Models

Autocorrelation of errors can also be taken as a sign that there are omitted dynamics in the regression.
That is yt,xty_t, x_tyt​,xt​ may be autocorrelated and their relationship varies over time. So we just use all the lagged values of y and x in an autoregressive distributed lag model

yt=α+ϕ1yt−1+...+ϕhyt−h+β0xt+β1xt−1+β2xt−2+...+βkxt−k+uty_t = α+ϕ_1y_{t−1} +...+ϕ_hy_{t−h} +β_0x_t +β_1x_{t−1} +β_2x_{t−2} +...+β_kx_{t−k} +u_tyt​=α+ϕ1​yt−1​+...+ϕh​yt−h​+β0​xt​+β1​xt−1​+β2​xt−2​+...+βk​xt−k​+ut​

Stability

The model is stable if the roots of the characteristic equation

Φ(z)=1−ϕ1z−ϕ2z2−…ϕhzh=0\Phi(z) = 1-\phi_1z-\phi_2z^2-\dots \phi_hz^h = 0Φ(z)=1−ϕ1​z−ϕ2​z2−…ϕh​zh=0

lie outside the unit circle

Consistency

Let θt=(α,ϕ1,...ϕh,β1...,βh)\theta_t = (\alpha, \phi_1, ... \phi_{h}, \beta_1 ..., \beta_h)θt​=(α,ϕ1​,...ϕh​,β1​...,βh​) and let Zt=(1,yt−1,...,yt−h,xt−1,...,xt−k)′Z_t = (1, y_{t-1},... , y_{t-h}, x_{t-1}, ..., x_{t-k})'Zt​=(1,yt−1​,...,yt−h​,xt−1​,...,xt−k​)′ and so the OLS estimator is

For this to be consistent as T tends to ∞\infin∞, we have two sufficient rules.

  1. Stability
T−1∑ZtZt′→stable, positive-definite matrixT^{-1} \sum Z_t Z_t' \rightarrow \text{stable, positive-definite matrix}T−1∑Zt​Zt′​→stable, positive-definite matrix
  • If this sum doesn’t stabilize, the “denominator” of your OLS fraction is essentially moving or becoming zero.
  • This is why ZtZ_tZt​ is implied stationary; if data is “trending” or exploding (non-stationary), the sum will keep growing to infinity, and the OLS math breaks down
  • i.e. each individual xtx_txt​ is stationary
  • and overall characteristic equation meets the stability condition
  1. Exogeneity
T−1∑Ztut→zero vectorT^{-1} \sum Z_t u_t \rightarrow \text{zero vector}T−1∑Zt​ut​→zero vector
  • Errors cannot be correlated with regressors
  • If your error term (the stuff you can’t see) is moving in sync with your independent variables, OLS will mistakenly “credit” that movement to your independent variables

SR and LR responses

The short run response, is what happens to yty_tyt​ to a change in xtx_txt​, by partial differentiation.

yt=α+ϕ1yt−1+...+ϕhyt−h+β0xt+β1xt−1+β2xt−2+...+βkxt−k+ut   ⟹  ∂yt∂xt=β0y_t = α+ϕ_1y_{t−1} +...+ϕ_hy_{t−h} +β_0x_t +β_1x_{t−1} +β_2x_{t−2} +...+β_kx_{t−k} +u_t \\ \ \\ \implies \frac{\partial y_t}{\partial x_t} = \beta_0yt​=α+ϕ1​yt−1​+...+ϕh​yt−h​+β0​xt​+β1​xt−1​+β2​xt−2​+...+βk​xt−k​+ut​ ⟹∂xt​∂yt​​=β0​

The long run response is the new steady-state for y∗y^*y∗

y∗=α+ϕ1y∗+...+ϕhy∗+β0x∗+β1x∗+...+βkx∗y^*= α+ϕ_1y^* +...+ϕ_hy^* +β_0x^* +β_1x^* +...+β_kx^*y∗=α+ϕ1​y∗+...+ϕh​y∗+β0​x∗+β1​x∗+...+βk​x∗

So we can collect terms, to get that

y∗(1−∑ϕ)=α+x∗(∑β)y^*(1 - \sum \phi) = \alpha + x^*(\sum \beta)y∗(1−∑ϕ)=α+x∗(∑β)

Thus, the LR response is as required:

∂y∗∂x∗=∑i=0kβi1−∑j=1hϕj\frac{\partial y^*}{\partial x^*} = \frac{\sum_{i=0}^k \beta_{i}}{1-\sum_{j=1}^h \phi_j}∂x∗∂y∗​=1−∑j=1h​ϕj​∑i=0k​βi​​

Polynomial DL Model

A general specification for the polynomial distributed lag (DL) model is

yt=α+β0xt+⋯+βqxt−q+ut =α+β(L)xt+uty_t = \alpha + \beta_0 x_t + \dots + \beta_q x_{t-q} + u_t \\ \ \\ = \alpha + \beta(L) x_t + u_tyt​=α+β0​xt​+⋯+βq​xt−q​+ut​ =α+β(L)xt​+ut​
  • utu_tut​ is assumed serially uncorrelated
  • β(L)\beta (L)β(L) =β0+β1L+...βqLq=\beta_0 + \beta_1L+... \beta_qL^q=β0​+β1​L+...βq​Lq is a lag polynomial

Rational DL Model

This time we have that

yt=α+β(L)λ(L)xt+vty_t = \alpha + \frac{\beta(L)}{\lambda(L)} x_t + v_tyt​=α+λ(L)β(L)​xt​+vt​
  • λ(L)=λ0+λ1L+...λpLp\lambda(L) = \lambda_0 + \lambda_1L + ... \lambda_p L^pλ(L)=λ0​+λ1​L+...λp​Lp

ARDL Model of order (p,q)

The ARDL model is

λ(L)yt=α+β(L)xt+ut\lambda (L) y_t = \alpha + \beta(L) x_t + u_tλ(L)yt​=α+β(L)xt​+ut​

This can also be written in the form of a MA

λ(L)yt=αλ(L)+β(L)xt+λ(L)vt\lambda (L) y_t = \alpha\lambda (L) + \beta(L) x_t + \lambda (L) v_tλ(L)yt​=αλ(L)+β(L)xt​+λ(L)vt​
  • where ut=λ(L)vtu_t = \lambda (L) v_tut​=λ(L)vt​ is itself an MA model
  • the alpha here is 1/p of the original alpha

You can throw in a deterministic trend or seasonal dummies too if you want.
