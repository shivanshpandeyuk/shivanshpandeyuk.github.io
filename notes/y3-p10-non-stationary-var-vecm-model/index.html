Lecture Notes

Motivation

We assume that the variables are I(1) for this analysis. In general many economic variables are considered I(1) (think GDP, Price level etc.)

If your variables xtx_txt​ are I(1)I(1)I(1), you have two “wrong” ways to estimate a standard VAR:

  • VAR in Levels: Estimating xtx_txt​ directly.
    • While it might work in very large samples, it is inefficient because it ignores the specific mathematical constraints that cointegration imposes on the relationships between variables.
  • VAR in First Differences (Δxt\Delta x_tΔxt​): Estimating only the changes.
    • This is misspecified (wrong) if the variables are cointegrated, because you throw away the “long-run” information. You are missing the “error correction” that pulls variables back together when they drift apart.
       The Solution: The Vector Error Correction Model (VECM)
      The VECM is the “best of both worlds.” It uses first differences (to handle the non-stationarity) but adds back the cointegrating residuals as right-hand-side variables.

VECM

Derivation of VECM

Let xt\bold x_txt​ be a n x 1 vector of variables. We assume it follows a VAR(p) in levels so:

xt=a0+a1xt−1+a2xt−2+⋯+apxt−p+etx_t = a_0 + a_1 x_{t-1} + a_2 x_{t-2} + \dots + a_p x_{t-p} + e_txt​=a0​+a1​xt−1​+a2​xt−2​+⋯+ap​xt−p​+et​

Subtracting xt−1x_{t-1}xt−1​ from both sides we get that:

Δxt=a0+ζ0xt−1+ζ1Δxt−1+ζ2Δxt−2+⋯+ζp−1Δxt−p+1+et\Delta x_t = a_0 + \zeta_0 x_{t-1} + \zeta_1 \Delta x_{t-1} + \zeta_2 \Delta x_{t-2} + \dots + \zeta_{p-1} \Delta x_{t-p+1} + e_tΔxt​=a0​+ζ0​xt−1​+ζ1​Δxt−1​+ζ2​Δxt−2​+⋯+ζp−1​Δxt−p+1​+et​
  • Δxt\Delta x_tΔxt​: The Short-Run dynamics (I(0) variables)
  • ζ0xt−1\zeta_0 x_{t-1}ζ0​xt−1​: The Long-Run relationship. This is the most important term.
  • ζ1…ζp−1\zeta_1 \dots \zeta_{p-1}ζ1​…ζp−1​: The lagged differences (also I(0)).

Cointegration and the Rank of ζ0\zeta_0ζ0​

The matix ζ0\zeta_0ζ0​ is the key to understanding how many long-run relationships exist. If there are rrr cointegrating vectors, we can decompose this into two matrices:

ζ0=α⏟n×rβ′⏟r×n\zeta_0 = \underbrace{\alpha}_{n\times r} \underbrace{\beta '}_{r\times n} ζ0​=n×rα​​r×nβ′​​
  • Notice that ζ0\zeta_0ζ0​ is an n × n matrix of rank r.
    β′\beta'β′** (The Cointegrating Vectors / The “Target”)**
    β\betaβ contains the weights of the long-run equilibrium.
  • When you multiply β′\beta'β′ by the variables xtx_txt​, the result is β′xt\beta' x_tβ′xt​.
  • Even though xtx_txt​ is I(1)I(1)I(1) (trending), the combination β′xt\beta' x_tβ′xt​ is I(0)I(0)I(0) (stationary).
  • Intuition: Think of x1x_1x1​ and x2x_2x2​ as two drunk walkers. They move randomly (I(1)I(1)I(1)), but they are connected by a leash (β\betaβ). The length of the leash (β′xt\beta' x_tβ′xt​) is stable (I(0)I(0)I(0)).

α\alphaα** (The Adjustment Coefficients / The “Correction”)**
α\alphaα tells the system how to react to the “leash.”
• If β′xt−1\beta' x_{t-1}β′xt−1​ is not zero, it means the variables are “out of balance” (the leash is stretched).
•α\alphaα determines the speed at which each variable in Δxt\Delta x_tΔxt​changes to pull the system back to the long-run equilibrium.

Visually if n =3, r = 1, for r = 1 only one unique LR equilbrium that makes the 3 variables stationary.

ζ0⏟(3×3)=[α11α21α31]⏟α (3×1)[β11β21β31]⏟β′ (1×3)\underbrace{\zeta_0}_{(3 \times 3)} = \underbrace{\begin{bmatrix} \alpha_{11} \\ \alpha_{21} \\ \alpha_{31} \end{bmatrix}}_{\alpha \ (3 \times 1)} \underbrace{\begin{bmatrix} \beta_{11} & \beta_{21} & \beta_{31} \end{bmatrix}}_{\beta' \ (1 \times 3)}(3×3)ζ0​​​=α (3×1)​α11​α21​α31​​​​​β′ (1×3)[β11​​β21​​β31​​]​​

The VECM model is now expressed solely in terms of I(0) variables.

Δxt=a0+α⏟constant(β′xt−1)⏟I(0)+ζ1Δxt−1⏟I(0)+⋯+et\Delta x_t = a_0 + \underbrace{\alpha}_{\text{constant}} \underbrace{(\beta' x_{t-1})}_{I(0)} + \underbrace{\zeta_1 \Delta x_{t-1}}_{I(0)} + \dots + e_tΔxt​=a0​+constantα​​I(0)(β′xt−1​)​​+I(0)ζ1​Δxt−1​​​+⋯+et​

Of course you need to know what the true number of cointegrating vectors, r, is.

Johansen Procedure (for testing r, and estimation)

To use the VECM, we must determine the exact number of cointegrating vectors (rrr). Johansen provides:

  • A Maximum Likelihood method to estimate these vectors, s.t. r cointegrating vectors.
  • Before that, also methods to test the rank of Π\PiΠ (which we called ζ0\zeta_0ζ0​) i.e. the hypothesis of there being exactly r cointegrating vectors .

Testing the rank of Π\PiΠ

We test the null hypothesis (HrH_rHr​) sequentially starting from r=0r=0r=0.

The Eigenvalues (λi\lambda_iλi​)
The procedure calculates nnn eigenvalues (λ1,λ2,…,λn\lambda_1, \lambda_2, \dots, \lambda_nλ1​,λ2​,…,λn​), ranked from largest to smallest. These λ\lambdaλ values represent the “strength” of the cointegrating links.

  • If λi=0\lambda_i = 0λi​=0, that specific combination is just random noise I(1)I(1)I(1)).
  • If λi>0\lambda_i > 0λi​>0, there is a stationary “bridge” (I(0)I(0)I(0)) between the variables.

Johansen uses these eigenvalues to build two specific Likelihood Ratio (LR) tests.
 A. The Trace Test (λtrace\lambda_{trace}λtrace​)
This is a joint test. It checks if the “remaining” eigenvalues are all zero.

  • Null (HrH_rHr​): There are rrr or fewer cointegrating vectors.
  • Alternative (HnH_nHn​): There are n cointegrating vectors.
Ltrace(r)=−T∑i=r+1nln⁡(1−λ^i)L_{trace}(r) = -T \sum_{i=r+1}^{n} \ln(1 - \hat{\lambda}_i)Ltrace​(r)=−Ti=r+1∑n​ln(1−λ^i​)

Strategy:

  • You start at r=0r=0r=0.
  • If you reject, you move to r=1r=1r=1.
  • You keep going and then stop the first time you fail to reject.

B. The Maximum Eigenvalue Test (λmax\lambda_{max}λmax​) This is a specific test. It checks only the very next eigenvalue.

Lmax(r,r+1)=−Tln⁡(1−λ^r+1)L_{max}(r, r+1) = -T \ln(1 - \hat{\lambda}_{r+1})Lmax​(r,r+1)=−Tln(1−λ^r+1​)
  • Null (H0H_0H0​): There are exactly rrr cointegrating vectors.
  • Alternative (H1H_1H1​): There are exactly r+1r+1r+1 vectors.

The “Critical Values” for the tests above change depending on whether you assume the data has a trend or an intercept.

CaseWhat’s in Cointegrating Vector (β)?What’s in the VECM (Δx)?When to use it?
Case 1No InterceptNo InterceptData has zero mean (Rare in Macro).
Case 2InterceptNo InterceptData has no trend, but the mean is not zero.
Case 3InterceptInterceptData has a linear trend (e.g., GDP).
Case 4Linear TrendInterceptCointegrating relationship changes over time.
Case 5Linear TrendQuadratic TrendData has accelerating trends (Very Rare).
  • Case 3 is the most common for macroeconomic data (GDP, Consumption, etc.) because it allows for linear growth in the levels of the variables.

Estimating the cointegrating vectors

Once r is chosen, VECM allows us to see the dynamics.

Δxt=a0+α⏟Speed(β′xt−1)⏟Error+∑ζiΔxt−i+et\Delta x_t = a_0 + \underbrace{\alpha}_{\text{Speed}} \underbrace{(\beta' x_{t-1})}_{\text{Error}} + \sum \zeta_i \Delta x_{t-i} + e_tΔxt​=a0​+Speedα​​Error(β′xt−1​)​​+∑ζi​Δxt−i​+et​

But what is the exact form of beta?

Beta is the matrix of co-integrating vectors, this can be non unique but we only know what it is in theory. We need to test if the estimate that we get from our software yields a beta that is close to what we theorised.

This test essentially asks: “If I force the model to behave exactly as my theory predicts, does the model’s ability to fit the data get significantly worse?”

1. The Hypotheses

  • Null Hypothesis (H0H_0H0​): The restrictions are valid.
  • The true β\betaβ is exactly (11−100−1)\begin{pmatrix} 1 & 1 \\ -1 & 0 \\ 0 & -1 \end{pmatrix}​1−10​10−1​​.
  • Alternative Hypothesis (H1H_1H1​): The restrictions are not valid. The β\betaβ matrix is free to be whatever the data wants.

2. The Test Procedure

Step 1: Estimate the Unrestricted Model You run the Johansen VECM procedure without forcing any specific numbers on β\betaβ (other than the bare minimum math constraints to make it solvable).

  • The software calculates the “Unrestricted Log-Likelihood” (LUL_ULU​).
  • This represents the best possible fit the data can achieve.

Step 2: Estimate the Restricted Model You re-run the VECM, but this time you hard-code the matrix β\betaβ to be your theoretical matrix.

  • The software optimizes the other parameters (α\alphaα, Γ\GammaΓ, etc.) around this fixed β\betaβ.
  • It calculates the “Restricted Log-Likelihood” (LRL_RLR​).
  • Note: Since you constrained the model, LRL_RLR​ will always be lower (worse) than LUL_ULU​. The question is: how much worse?

Step 3: Calculate the LR Statistic The formula is: LR=−2(LR−LU)LR = -2 (L_R - L_U)LR=−2(LR​−LU​) (Or equivalently: 2(LU−LR)2(L_U - L_R)2(LU​−LR​)).

  • This statistic measures the “distance” between the unrestricted fit and the restricted fit.
  • If the restriction is harmless (the theory is right), LR≈LUL_R \approx L_ULR​≈LU​, so the statistic is close to 0.
  • If the restriction is wrong (the theory contradicts the data), LR≪LUL_R \ll L_ULR​≪LU​, so the statistic is large.

3. The Decision Rule (Degrees of Freedom)

You compare your calculated LR statistic to a Chi-Squared (χ2\chi^2χ2) distribution.

  • Degrees of Freedom (dfdfdf): This is the number of “constraints” you added.
  • In your case, a free β\betaβ matrix has many free parameters.
  • Your theoretical β\betaβ has zero free parameters (you fixed every single number: 1, -1, 0…).
  • The dfdfdf is the count of those specific numbers you forced upon the model (minus the normalisation constraints required anyway).
  • Conclusion:
  • If LR>Critical ValueLR > \text{Critical Value}LR>Critical Value: Reject H0H_0H0​. The restriction is too strict. The tea markets are not perfectly integrated as you thought.
  • If LR<Critical ValueLR < \text{Critical Value}LR<Critical Value: Fail to reject H0H_0H0​. The drop in likelihood was minor. The data is consistent with the Law of One Price.

Summary

The LR test is a “penalty check.” It calculates how much accuracy you lose by forcing the tea prices to follow your theoretical rules (T1=T2T_1 = T_2T1​=T2​ and T1=T3T_1 = T_3T1​=T3​). If you lose too much accuracy, the test fails, and your theory is rejected.

The “Granger Causal” Requirement

For the system to be “Error Correcting,” at least one variable must respond to the error. We must have (at least some) Granger Causal relationships between the cointegrating variables, for the relations to eventually be obeyed.

This creates a Granger Causality chain:

  1. If β′xt−1≠0\beta' x_{t-1} \neq 0β′xt−1​=0, the system is “out of equilibrium.”
    2. The α\alphaα coefficient acts as a weight. If large, the variable xxx moves quickly to fix the error.
    3. If αi=0\alpha_i = 0αi​=0, variable iii is Weakly Exogenous.
  • It doesn’t care about the long-run error; other variables must do the work to move toward it.

Example: dividend-price ratio should be I(0) If Prices (ppp) and Dividends (ddd) drift apart, the “dividend yield” (d−p)(d-p)(d−p) becomes the error term.

  • If αp\alpha_pαp​is significant, it means Prices adjust to meet Dividends.
  • If αd\alpha_dαd​ is significant, it means Dividends adjust to meet Prices. At least one must be non-zero, or they aren’t actually cointegrated!

Identification (Non-Uniqueness of β\betaβ)

The Johansen test tells us the rank rrr, but it doesn’t give us a unique β\betaβ.
**If β\betaβ is a set of cointegrating vectors, then any linear combination of them (multiplying by an invertible matrix RRR) is also a valid set of cointegrating vectors. **

The Mathematical Proof: If we have an invertible r×rr \times rr×r matrix RRR, we can insert it into our long-run matrix:

ζ0=αβ′=(αR−1)(Rβ′)=α~β~′\zeta_0 = \alpha \beta' = (\alpha R^{-1})(R \beta') = \tilde{\alpha} \tilde{\beta}'ζ0​=αβ′=(αR−1)(Rβ′)=α~β~​′

This shows that since the sum of any two cointegrating vectors will itself be a cointegrating vector, the cointegrating vectors are only identified up to arbitrary linear transforms. In particular it may be very difficult to give any sensible structural interpretation to the estimated cointegrating vectors.

The Problem: The computer might output a β~\tilde \betaβ~​ that is statistically correct but economically gibberish.

The Rule: To identify “structural” cointegrating vectors, we must impose r2r^2r2 restrictions.

Interpreting the estimated VECM

Really what we care about are the common stochastic trends and the **impulse response functions. **

Define: Common Stochastic Trends

There is a beautiful symmetry between cointegration and trends:

  • In a system of nnn variables with no cointegration, there are nnn independent “random walks” (permanent shocks) driving the system.
  • If there are rrr cointegrating vectors (bonds), they “tie” the variables together.
  • This leaves only k=n−rk = n - rk=n−r independent permanent shocks, known as Common Stochastic Trends.

Example: If you have 3 interest rates (n=3n=3n=3) that are all tied to 2 long-run spreads (r=2r=2r=2), then there is only 3−2=13 - 2 = \mathbf{1}3−2=1 common trend (e.g., the general level of market volatility) driving all of them.

Turning VECM into a MA process

This procedure explains how we move from a model that looks at short-run changes back to a model that shows the long-run levels and trends.
Can’t do typical matrix inversion In a stationary VAR, we just flip the lags to the other side to see how shocks ε\varepsilonε) create the data. But in our simplest case a VAR(1):

xt=(I+αβ′)xt−1+εtx_t = (I + \alpha\beta')x_{t-1} + \varepsilon_txt​=(I+αβ′)xt−1​+εt​

The term (I+αβ′)(I + \alpha\beta')(I+αβ′) has a unit root [literally the ‘1’ i.e. I]. If you try to invert it, the math “breaks” because the shocks never die out—they accumulate forever into a trend.

*Where is this term from? Expand to see*

This term comes from a simple derivation, beginning with a VAR in levels

xt=Axt−1+εtx_t = A x_{t-1} + \varepsilon_txt​=Axt−1​+εt​

Subtract by xt−1x_{t-1}xt−1​ on both sides and you get

Δxt=(A−I)xt−1+εt\Delta x_t = (A-I) x_{t-1} + \varepsilon_tΔxt​=(A−I)xt−1​+εt​

And recall that we defined the coefficient on xt−1=αβ′  ⟹  A−I=aβ′x_{t-1} = \alpha \beta ' \implies A - I = a\beta 'xt−1​=αβ′⟹A−I=aβ′

Use a stacking trick again To fix this, we stop looking at xtx_txt​ (the “exploding” level) and look at two things that are I(0)

  • Δxt\Delta x_tΔxt​: The changes (always stationary for I(1)I(1)I(1) data).
  • βxt′\beta x_t'βxt′​: The cointegrating relation (the “leash” which is stationary by definition).

We stack them into a new vector: zt=[Δxtβ′xt]z_t = \begin{bmatrix} \Delta x_t \\ \beta' x_t \end{bmatrix}zt​=[Δxt​β′xt​​]

Interpretation The equation you found for the “Permanent” (Trend) part of the level of xxx is:

Think of ∑εt\sum \varepsilon_t∑εt​ as a “pile” of every shock that has ever hit the economy.

  • Usually, in a random walk, that pile just grows and grows.
  • The matrix C(1)C(1)C(1)is a filter that sits in front of that pile.

Note here, the matrix C(1)C(1)C(1) has Reduced Rank (n−rn-rn−r).

  • The Math: If you have 3 variables (n=3) and 2 leashes (r=2), the rank is 1.
  • The Significance: This means the matrix C(1)C(1)C(1) takes 3 independent shocks and collapses them into one single direction.
  • The Result: Even if you hit the system with 3 different surprises, in the long run, all 3 variables end up moving along the exact same path. They are mathematically forbidden from drifting apart.

Also note that β′C(1)=0\beta' C(1) = 0β′C(1)=0 ← stability proof

The Mechanics: β′\beta'β′ represents the combination of variables that is supposed to be stable (e.g., the gap between Consumption and Income).

The Result: When you multiply the “Trend” by the “Leash” (β′\beta'β′), you get zero.

The Significance: This proves that the Trend never enters the Leash.

  • If the trend pushes Income up by US$1,000, the C(1)C(1)C(1) matrix ensures it also pushes Consumption up by exactly the amount needed to keep the ratio identical.
  • The “Trend” moves the variables, but it cannot move the relationship between them.
